## Microsoft Dislike Viewer
In a corporate environment, you don't have many options.

### Why this extension?
Microsoft disabeld the dislike counter on their articles some time ago. This is a browser extension to bring back dislike counts and badge for the hot-garbage site [https://www.msn.com/](https://www.msn.com/).

You can install this extension here as well - [MSN Dislike Viewer](https://microsoftedge.microsoft.com/addons/detail/msn-dislike-viewer/lfpdbdjekljiplnfhigdjopggaleedfh).
